Casa O'Faydin Source

The game project, the design docs, and a handoff package you can give to a collaborator such as Microsoft Copilot Cowork.

Casa O'Faydin is a phone-first role-playing game Blake is building in Godot 4.3. The first town is Port Paradise, a busy harbor you can already walk around in a browser. The source is licensed under CC BY-NC-SA 4.0, so you can see the code and make your own mods if you give credit to Blake Farthing and do not sell the work. See the license below.

The project, in short

The live web build uses Godot 4.3, the Compatibility renderer, and threads off. Art is written in GDScript, not bulky imported models. A required project setting keeps the town from vanishing on the web.

  • You can walk around Port Paradise with twin-stick controls: the left stick moves and strafes, the right stick looks around.
  • Arrival-forms character creation and tavern games (chess, checkers, and dominoes) have their logic and tests done. The on-screen UI for those is still to come.
  • Work follows a scope lock. Finish Phase 1 before starting Phase 2. New ideas go into the phase list, not into the current build.
  • On the evening of November 10, 2026, new design docs landed for trade, founding towns, couriers, government and Latin names, a lore bible, and built-in modding. Those are design only, with a data file of Latin word lists.

Make your own mods

Blake wants everyone to be able to see the code and make their own mods. Packs should feel Sims-style: most new things are data, not a new engine. The in-game workshop is still a plan, but you can already read the data files and the design for a mods/ folder and load order.

Read the modding guide

In short: give credit to Blake Farthing, do not sell your pack, and share it under the same CC BY-NC-SA 4.0 license. Start with the JSON in godot/data/, the plan in design/modding-tools-v0.1.md, and the tiny examples in the guide.
