# Casa O'Faydin — source and Cowork handoff

This folder is a handoff package for collaborators, including Microsoft Copilot Cowork. It holds a ready-to-paste prompt, a project brief, a tech guide, a task board, a combined Word document, the Godot 4.3 project source, and stills of the current Port Paradise look.

## Start here

1. Read `COWORK-PROMPT.md` (or paste it into Copilot Cowork).
2. Then read `PROJECT-BRIEF.md`, `TECH-GUIDE.md`, and `TASK-BOARD.md`.
3. The same four documents are combined in `Casa-OFaydin-Cowork-Handoff.docx` for Word or OneDrive.
4. The Godot project is in `godot/`. Open it with Godot 4.3.
5. Earlier design specs are in `docs/`. The November 10 minutiae docs are in `design/` (start with `design/SUMMARY.md`). Art baseline stills are in `art-previews-v3/`. Latin word lists are in `godot/data/latin_names.json`.
6. Mods are welcome. Start with `MODDING.md`.
